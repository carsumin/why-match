## 📌 프로젝트 소개

**WhyMatch**는 해커톤을 위한 팀 매칭 플랫폼입니다.

단순히 "같이 할 사람"을 찾는 게 아닙니다.  
*왜* 이 프로젝트를 하고 싶은지, *어떤 사람*과 함께하고 싶은지 —  
이유와 가치 기반으로 팀을 연결합니다.

> **"맞는 팀이 맞는 결과를 만든다."**

해커톤에서 팀 구성이 성패를 가르는 핵심 요소임에도 불구하고,  
대부분의 참가자들은 여전히 오픈 채팅방이나 에브리타임 게시글에 의존합니다.  
WhyMatch는 그 불편함을 해결하기 위해 만들어졌습니다.

## 🚀 로컬 실행

```bash
# 저장소 클론
git clone https://github.com/carsumin/why-match.git
cd why-match

# 패키지 설치
npm install

# 개발 서버 실행
npm run dev
```

`http://localhost:3000` 에서 확인하세요.
